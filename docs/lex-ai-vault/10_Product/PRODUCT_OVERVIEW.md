# Product Overview

## TL;DR
- LEX AI — AI-студия контента для Instagram-блогеров внутри Telegram Mini App.
- Главный сценарий: «Дай ссылку на Reels — получи разбор + свой сценарий».
- Доп. инструменты: сценарий с нуля, карусель, подпись, контент-пакет.
- Удержание: план недели + архив + уведомления.
- Монетизация: подписка ЮKassa, paywall показывается **после** демонстрации ценности.

## Когда читать этот файл
Когда нужен общий обзор продукта без деталей. Для конкретных областей — соответствующие документы.

## Что делает продукт
1. Разбирает любой Reels (свой или чужой): хук, структура, метрики, психотриггеры.
2. Адаптирует механику под нишу автора: 3 темы или своя идея.
3. Собирает полный сценарий (20 полей: хук / озвучка / раскадровка / визуал / монтаж / CTA / подпись / хэштеги / альтернативы / риски).
4. Генерирует карусели (6 слайдов), подписи (5 стилей), контент-пакеты (Reel + Carousel + Caption).
5. Хранит всё в проекте (Library) и в недельном плане.

## Позиционирование (рабочее)
- **Для кого:** Instagram-эксперты и креаторы, которые хотят регулярно постить, но не знают, что снимать.
- **Что даёт:** превращает чужой вирусный Reels в твой собственный готовый к съёмке сценарий.
- **В чём отличие:** не «генератор постов», а **студия адаптации механик** — не делает за тебя, а помогает воспроизвести то, что работает.

См. [[50_Marketing/POSITIONING]] для маркетингового языка.

## Главные разделы продукта
- **Главная** — рабочая, после онбординга. Прогресс, последние материалы, быстрый ввод ссылки.
- **Создать** — хаб 6 карточек: Разобрать / Сценарий / Карусель / Подпись / Пакет / Идеи.
- **План** — недельный план публикаций, статусы, добавление из сценария.
- **Профиль** — список проектов, настройки, тариф.

См. [[20_UX_UI/SCREEN_MAP]] для полной карты экранов.

## Канал доставки
Приложение работает как **Telegram Mini App**. Auth — через `initData`. Это техническая поверхность, не продуктовое позиционирование: в текстах UI слово «Telegram» юзеру не показывается, продукт = AI-студия про Instagram.
