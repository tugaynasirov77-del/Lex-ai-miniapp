# Product Decisions

## TL;DR
- Журнал ключевых продуктовых решений LEX AI с обоснованием.
- При конфликте новой задачи с DEC-NNN → сначала обсудить с владельцем, потом менять.

## Когда читать этот файл
Когда решение «почему так» неочевидно из кода. Сначала ищи DEC-NNN, потом меняй.

> [!important]
> Единый источник правды по истории продуктовых решений.

## DEC-001 — Одноразовый onboarding
**Статус:** утверждено
**Дата:** 2026-06-17
**Решение:** Welcome-экраны показываются один раз новому юзеру; гейт = `localStorage` + `user_prefs.onboarding_completed` + наличие проектов.
**Почему:** существующие 341 юзер не должны видеть welcome заново; рекламные слайды не место для рабочего пользователя.
**Последствия:** все возвращающиеся юзеры попадают сразу на Home.
**Что отменяет:** показ рекламной главной как «домашней страницы».
**Связанные документы:** [[ONBOARDING]], [[USER_JOURNEY]].

## DEC-002 — Рабочая главная после onboarding
**Статус:** утверждено
**Дата:** 2026-06-18
**Решение:** Home — рабочий дашборд (greeting + ввод ссылки + прогресс + последние материалы), а не рекламная страница.
**Почему:** возврат юзера каждый раз на рекламу — антипродуктовый паттерн.
**Последствия:** старая презентационная Home архивирована, новая Home собирается из Plan API + listProjectDrafts.
**Связанные документы:** [[USER_JOURNEY]], [[90_Archive/REJECTED_AND_OBSOLETE_IDEAS]].

## DEC-003 — Первый разбор Reels бесплатно
**Статус:** утверждено
**Дата:** ранее (зафиксировано)
**Решение:** первый разбор Reels должен быть полностью бесплатным и содержать основную ценность (хук, структура, адаптация, сценарий).
**Почему:** без демонстрации ценности нельзя продавать подписку.
**Последствия:** Free тариф = 3 разбора/мес, не 0.
**Связанные документы:** [[MONETIZATION]].

## DEC-004 — Демонстрация ценности до paywall
**Статус:** утверждено
**Дата:** ранее
**Решение:** жёсткий paywall запрещён до первого полноценного разбора. Paywall показывается на `value_moment` (после первого сценария) или `limit_reached` (после исчерпания квоты).
**Почему:** ранний paywall убивает конверсию (метрика: 0 платящих при 341 юзере).
**Последствия:** `PaywallSheet` спроектирован как bottom-sheet (не fullscreen), без таймеров/скидок.
**Связанные документы:** [[MONETIZATION]].

## DEC-005 — 2-3 бесплатных разбора с полной ценностью
**Статус:** утверждено
**Дата:** ранее
**Решение:** на Free тарифе 3 разбора/мес, каждый — с полным анализом и адаптацией. Не урезать ценность ради конверсии.
**Почему:** урезанный разбор не покажет, за что платить.
**Последствия:** `lib/tiers.ts` → Free.reel_decode = 3/month.
**Связанные документы:** [[MONETIZATION]].

## DEC-006 — Разовая покупка + подписка
**Статус:** утверждено (Lite-пакет 390 ₽), не реализовано
**Дата:** ранее
**Решение:** должно быть два способа платить: подписка Pro/Pro+ для регулярной работы и разовый Lite-пакет (10 разборов за 390 ₽) для нерегулярных юзеров.
**Почему:** не все хотят подписку; разовая покупка снижает барьер.
**Последствия:** новый endpoint в `app/api/billing/`, кнопка в `PaywallSheet`.
**Связанные документы:** [[MONETIZATION]], [[03_NEXT_ACTIONS]] пункт 6.

## DEC-007 — Возможность модернизировать свою идею
**Статус:** утверждено, реализовано частично
**Дата:** ранее
**Решение:** юзер может ввести свою идею и попросить LEX усилить её.
**Где есть:** `AdaptedTopicsBlock` → «У меня есть своя идея» (refine в контексте разбора).
**Где нет:** отдельной самостоятельной вкладки «Своя идея с нуля» без референса нет.
**Что считается замещением:** `ReelScriptGeneratorCard` (сценарий по теме без референса).
**Связанные документы:** [[FEATURES]].

## DEC-008 — Интерактивный недельный план
**Статус:** утверждено, реализовано
**Дата:** 2026-06-18
**Решение:** план = кликабельные дни, материалы с action-sheet (отметить готовым / опубликованным / убрать), прогресс-бар, переключение недель.
**Почему:** статичный план — это документ, а должно быть рабочее место.
**Связанные документы:** [[FEATURES]] (раздел Plan).

## DEC-009 — Отказ от старой кнопки «Открыть полный сценарий»
**Статус:** утверждено
**Дата:** ранее
**Решение:** чёрная кнопка «Открыть полный сценарий» в прежнем виде убрана.
**Почему:** запутывала, дублировала action.
**Чем заменено:** AdaptedTopicsBlock → «Создать мой Reels» → `PersonalScriptScreen`.
**Связанные документы:** [[90_Archive/REJECTED_AND_OBSOLETE_IDEAS]].

## DEC-010 — Отказ от логики «скрепки»
**Статус:** утверждено
**Дата:** ранее
**Решение:** старая логика со скрепкой и привязанным блоком идей отменена.
**Почему:** не давала ценности, путала юзера.
**Связанные документы:** [[90_Archive/REJECTED_AND_OBSOLETE_IDEAS]].

## DEC-011 — IG-only продукт (pivot)
**Статус:** утверждено, реализовано
**Дата:** 2026-06-13 (`QUOTA_EPOCH`)
**Решение:** все TG-функции из UI скрыты (агенты, посты в канал, конкуренты в TG). Продукт = IG-AI-студия.
**Почему:** фокусировка ресурсов, IG-функции дали ценность быстрее.
**Что осталось:** Telegram = канал доставки (Mini App), но в текстах UI слова «Telegram» юзеру не показывается.
**Связанные документы:** [[02_CURRENT_STATE]].

## DEC-012 — 4 вкладки нав-бара
**Статус:** утверждено, реализовано
**Дата:** 2026-06-18
**Решение:** Главная / Создать / План / Профиль. Настройки — внутри Профиля.
**Связанные документы:** [[20_UX_UI/SCREEN_MAP]].

## DEC-013 — «Создать» = хаб инструментов с табами
**Статус:** утверждено, реализовано
**Дата:** 2026-06-19
**Решение:** вкладка «Создать» = хаб 6 карточек → `ToolsScreen` с табами на каждый инструмент. С «Обзора» проекта генераторы убраны.
**Почему:** раньше все кнопки хаба вели на одно место (свалка). Теперь 1 тап = инструмент.
**Связанные документы:** [[FEATURES]], [[20_UX_UI/SCREEN_MAP]].

## DEC-014 — Streak за полезные действия
**Статус:** утверждено, реализовано
**Дата:** 2026-06-19
**Решение:** «активный день» = есть полезное событие (script_saved / script_added_to_plan / content_status_changed / content_marked_published / project_created) или created/updated content_drafts (≠ rejected). Просто вход (`app_opened`) не считается.
**Почему:** старый streak за вход = метрика тщеславия.
**Связанные документы:** [[FEATURES]] (раздел Streak).
