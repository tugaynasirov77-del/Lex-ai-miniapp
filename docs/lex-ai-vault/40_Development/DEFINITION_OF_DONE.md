# Definition of Done

## TL;DR
- Чек-лист, который надо пройти перед мержем PR.
- Разный набор для разных типов PR (фича / баг-фикс / рефакторинг / docs).

## Когда читать этот файл
Перед коммитом и перед `gh pr merge`.

## Универсальные требования (все PR)

- [ ] `npx tsc --noEmit` — чисто.
- [ ] Код стартовал с актуального main (`git checkout main && git pull` перед веткой).
- [ ] Коммит-сообщение в формате `feat: ...` / `fix: ...` / `refactor: ...` / `docs: ...`.
- [ ] PR заголовок ≤ 70 символов, в body есть «что» и «почему».
- [ ] Нет случайных правок в чужих зонах (см. командное разделение).
- [ ] Нет секретов/ключей в diff.

## Новая фича

- [ ] Универсальные требования + ниже.
- [ ] Изменены тематические заметки Vault (`02_CURRENT_STATE`, `10_Product/FEATURES`, `40_Development/CHANGELOG`).
- [ ] Если требуется миграция БД — `supabase/migrations/*.sql` добавлен.
- [ ] Если миграция нужна — упомянуто в PR body, что её надо применить перед мержем.
- [ ] Empty/error состояния используют `StateBlock` (либо явное обоснование).
- [ ] Аналитика: добавлены `track(...)` события, если фича пользовательская.
- [ ] Mobile-first: проверено в WebView-формате (узкая ширина).
- [ ] Учтены лимиты тарифов (free/pro/business) — если фича квотированная.

## Баг-фикс

- [ ] Универсальные требования + ниже.
- [ ] В PR body — описание корня бага, не симптома.
- [ ] Если найден в `BUGS.md` — перенесён из «Открытые» в «Закрытые».
- [ ] Если был зафиксирован в Vault как «требует проверки» — снят флаг.

## Рефакторинг

- [ ] Универсальные требования + ниже.
- [ ] Поведение НЕ изменилось (zero functional diff).
- [ ] Если убирался legacy-код, подтверждено что он не вызывается (grep).
- [ ] Если тронут `TECHNICAL_DEBT.md` пункт — обновлён статус.

## Документация

- [ ] Универсальные требования + ниже.
- [ ] Не нарушены принципы экономии токенов (см. [[60_AI_Workflows/CLAUDE_CODE_PROTOCOL]]).
- [ ] Нет дублирования между документами.
- [ ] Все `[[ссылки]]` ведут на существующие файлы.
- [ ] Обновлены `updated:` поля в frontmatter изменённых документов.

## API/Backend

- [ ] Универсальные требования + ниже.
- [ ] Авторизация: `verifyInitData` присутствует.
- [ ] Owner-check проекта если ресурс per-project.
- [ ] Quota: `enforceQuota`/`checkQuota` если action квотируется.
- [ ] `runtime = "nodejs"` явно (не Edge).
- [ ] `maxDuration` установлен если запрос > 10 сек.
- [ ] Расход в `project_usage` если AI-генерация.
