# Rejected and Obsolete Ideas

## TL;DR
- Список отменённых решений и устаревших концепций, чтобы не возвращаться к ним.
- Код, связанный с ними, может ещё существовать в репо — не удалять без проверки.

## Когда читать этот файл
Когда возникает идея «а давай вернём X» — сначала сюда. Возможно, X уже отменён с обоснованием.

> [!important]
> Единый источник правды по отменённым идеям.

## Архив

### OBS-001 — Чёрная кнопка «Открыть полный сценарий»
- **Что было:** на одном из экранов была чёрная кнопка «Открыть полный сценарий», которая открывала отдельный сценарий-вид.
- **Почему отменено:** запутывала пользователя, дублировала action из AdaptedTopicsBlock.
- **Чем заменено:** `AdaptedTopicsBlock` → «🎬 Создать мой Reels» → `PersonalScriptScreen`.
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-009.

### OBS-002 — Логика «скрепки»
- **Что было:** иконка-скрепка с привязанным блоком идей.
- **Почему отменено:** не давала ценности, путала юзера, не вписывалась в логику адаптации.
- **Чем заменено:** прямой поток Decoder → Adapted Topics → Personal Script.
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-010.

### OBS-003 — Старая рекламная Home
- **Что было:** при каждом входе в Mini App показывалась презентационная страница (BannerCarousel со слайдами «LEX AI пишет за тебя», «7 идей на неделю» и т.п.).
- **Почему отменено:** работающему юзеру не нужна реклама. Это домашняя страница, а не лендинг.
- **Чем заменено:** новая Home (greeting + ввод ссылки + прогресс + последние материалы).
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-002.
- **Где остался код:** `public/slide-*.jpg` — изображения слайдов; legacy `BannerCarousel` в Git history.

### OBS-004 — Повторный показ Welcome
- **Что было:** Welcome потенциально мог показаться юзеру повторно при отсутствии серверного флага.
- **Почему отменено:** существующие 341 юзер не должны видеть welcome.
- **Чем заменено:** гейт `useWelcomeGate` с тремя условиями (`localStorage` + `user_prefs.onboarding_completed` + наличие проектов).
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-001.

### OBS-005 — Жёсткий paywall до первого разбора
- **Что было:** идея делать paywall сразу после онбординга.
- **Почему отменено:** убивает конверсию (юзер не увидел ценности).
- **Чем заменено:** Free = 3 разбора/мес, paywall на `value_moment` или `limit_reached`.
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-004, DEC-005.

### OBS-006 — Telegram-постинг как основной use-case
- **Что было:** до 2026-06-13 продукт позиционировался как «AI-фабрика контента для TG+IG» с агентами для постинга в канал, анализом TG-конкурентов, недельным планом постов в TG.
- **Почему отменено:** pivot на IG-only — фокусировка, IG-функции давали ценность быстрее.
- **Чем заменено:** IG-only AI-студия. TG = канал доставки (Mini App), но не продуктовое позиционирование.
- **Где остался код:** legacy в `LexCreateScreen`, `InboxScreen`, `TaskInput`, `lib/lexAI.ts` (агенты), `app/api/agent/`, `app/api/council/`, `app/api/orchestrate/`.
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-011.

### OBS-007 — Montage pipeline (автомонтаж Reels из сырых видео)
- **Что было:** в корневом `CLAUDE.md` описан как «текущий приоритет» MVP за 2 недели.
- **Почему отменено:** объём 2-недельного MVP не покрывал монтаж. Pivot ушёл в сторону сценариев и адаптации механик, монтаж юзер делает сам в CapCut.
- **Чем заменено:** Personal Script с раскадровкой и подсказками по монтажу (текстом), без видео-движка.
- **Где остался код:** упоминания в `CLAUDE.md` (корневой) — устарели.

### OBS-008 — Старая 3-вкладочная нав-бар (Главный/Профиль/Настройки)
- **Что было:** до 2026-06-18 BottomTabBar содержал 3 таба.
- **Почему отменено:** «Создать» и «План» — основные действия, должны быть в нав-баре. Настройки уходят внутрь Профиля.
- **Чем заменено:** 4 таба (Главная/Создать/План/Профиль).
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-012.

### OBS-009 — «Создать» как алиас на проект
- **Что было:** до 2026-06-19 таб «Создать» открывал `project` с вкладкой «Обзор», где сложены все генераторы.
- **Почему отменено:** все 5 карточек хаба вели на одно место — антипродуктовая свалка.
- **Чем заменено:** хаб → `ToolsScreen` с табами под каждый инструмент.
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-013.

### OBS-010 — Streak за вход в приложение
- **Что было:** `/api/streak` считал день активным по созданию `content_drafts`, что приближено к «вход + ткнул куда-то».
- **Почему отменено:** метрика тщеславия. Не отражает реальную полезную активность.
- **Чем заменено:** учёт полезных событий аналитики + смены статусов материалов. См. `app/api/streak/route.ts`.
- **Связанные решения:** [[10_Product/PRODUCT_DECISIONS]] DEC-014.

### OBS-011 — Apple/Google IAP, Telegram Stars
- **Что было:** идея платежей через нативные сторы или TG Stars.
- **Почему отменено:** TG Mini App — это web; IAP не применим. Stars-канал есть в `tiers.ts` (`priceStars`), но в UI не активирован.
- **Чем заменено:** ЮKassa. См. [[30_Technical/INTEGRATIONS]].

## Что делать, если идея «вернулась»
1. Найди соответствующий OBS-NNN.
2. Проверь, остаётся ли причина отказа актуальной.
3. Если ситуация изменилась — обсуди с владельцем продукта.
4. Если возвращаешь — добавь новый DEC-NNN в [[10_Product/PRODUCT_DECISIONS]] и пометь, что отменяет OBS-NNN.
