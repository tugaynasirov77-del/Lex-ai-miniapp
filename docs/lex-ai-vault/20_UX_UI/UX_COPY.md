# UX Copy

## TL;DR
- Ключевые тексты UI собраны здесь для быстрой правки и консистентности.
- Тон: уверенный, продуктовый, без воды. Без обращения «друг», без эмодзи как маркер списка.
- Запрещено: «гайд», «инсайты», «эксклюзивно», слово «бот», вымышленные кейсы/цифры.

## Когда читать этот файл
При правке текста UI / новом экране. Не меняй копи без сверки с этим документом.

## Принципы тона
- Уверенный, без подобострастия.
- Обращение на «ты» в продуктовых текстах, «вы» — в первых экранах онбординга (пока юзер новый, чтобы не сразу панибратство).
- Никаких «друг», «привет всем».
- Эмодзи — только осмысленные внутри текста, не как маркер.
- IG-only: слово «канал» (TG) запрещено в продуктовом UI. См. [[10_Product/PRODUCT_DECISIONS]] DEC-011.
- Слово «бот» **запрещено** — продукт = AI-студия, не бот (зафиксировано в памяти).
